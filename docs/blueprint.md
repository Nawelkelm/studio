# **App Name**: 3D Print Profit

## Core Features:

- Cost Input: Allow users to input costs associated with 3D printing (material, electricity, machine depreciation, etc.).
- Price Input: Enable users to input the selling price of their 3D printed items.
- Profit Calculation: Calculate the profit margin based on the input costs and selling price.
- Profit Display: Display the calculated profit margin in a clear and understandable format.
- Profile Management: Provide a feature to save and load calculation profiles for different 3D printing projects.
- AI Pricing Assistant: Use a generative AI tool that offers pricing suggestions, by prompting for the product description, material used and printing time.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) to evoke the tech nature of 3D printing.
- Background color: Off-white (#F5F5F5), near to white, providing a clean, neutral backdrop.
- Accent color: Teal (#008080) for buttons and highlights to draw the user's attention and offer some visual relief.
- Body and headline font: 'Inter' sans-serif, providing a modern, machined, objective, neutral look.
- Use minimalist icons representing costs, profits, and 3D printing processes.
- The calculator will feature a simple, tabular layout. Input fields for costs and pricing will be clearly labeled and easy to access.
- Subtle animations on calculations and transitions.
